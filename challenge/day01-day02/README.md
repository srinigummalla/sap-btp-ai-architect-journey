# Days 1 and 2 SAP AI architecture lab

This is an independent learning lab for Srini Gummalla's SAP BTP AI architect journey.
All purchase orders, receipts, invoices, suppliers and company codes here are synthetic.
The lab makes no SAP calls, uses no credentials, and posts no financial transactions.

1. Follow the detailed Day 1 and Day 2 guide supplied with this kit.
2. Fill in the Day 1 Markdown templates under `docs/day-01`.
3. Read `docs/day-02/process-map.md` and `data/README.md`.
4. Fill `docs/day-02/manual-analysis.md` BEFORE opening the answer key.
5. Complete the three TODOs in `src/student_classifier.py`.
6. From this folder, run `python src/evaluate.py` (or `py` / `python3`).
7. If needed, compare your work with `src/reference_classifier.py`.
8. Record your results and explain the decisions in your own words.

The reference can be checked with `python src/evaluate.py --reference`.
No third-party packages are required. Python 3.10 or newer is sufficient.
The 12 cases are visible learning fixtures, not a held-out benchmark or proof of SAP production behavior.
Keep files in this folder so their relative paths remain valid.

Repository destination: https://github.com/srinigummalla/sap-btp-ai-architect-journey
Suggested branch: `day-01-02-foundation`.
Copy the supplied `challenge/day01-day02` folder into your existing repository; preserve existing files.
